# 账号模块第四步：前端账号流程

阶段记录：本页保留账号阶段的25项前端及198项后端测试快照。后续已接入剧组基础和岗位管理，并抽出共享同源请求客户端；最新测试及构建状态见[岗位管理说明](member-roles.md)。测试使用模拟fetch、数据库/队列替身、fakeredis及回环SMTP，不代表真实依赖端到端、性能或完整安全验收。

## 1. 核心代码

| 文件 | 职责 |
|---|---|
| `frontend/src/api/http.ts`、`accounts.ts` | 共享同源请求与CSRF、账号响应白名单校验、受控错误与超时；不自动重试写请求 |
| `frontend/src/auth/AuthProvider.tsx` | 以本人资料接口确认会话，隔离过期响应，身份变化清除私有查询缓存，多标签页通知重新检查 |
| `frontend/src/auth/AccountScreens.tsx` | 登录、分步邮箱注册、昵称必填、资料冲突与显式恢复 |
| `frontend/src/App.tsx` | 会话检查、匿名/不可用、资料待完善、工作台与只读布局预览的页面切换 |
| `frontend/src/Workspace.tsx` | 工作台外壳；实际登录显示本人昵称，预览始终有明确标识 |
| `frontend/src/components/ScreenBoundary.tsx` | 页面加载/渲染失败时静态提示，由用户明确重载，不重放提交 |

## 2. 用户流程与失败处理

1. 启动后读取`GET /api/v1/users/me`；会话过期进入登录入口，服务故障显示不可用。布局预览需明确选择，不产生登录态。
2. 注册分为申请验证码、校验验证码、设置密码、注册完成。202只显示“受理”，不声称送达；重发冷却读取服务端`resend_after_seconds`。验证或申请结果未知时不继续使用可能已失效的旧验证码请求。
3. 注册不会自动登录。密码按Unicode码点计15—128字符，不裁剪空格；注册凭证只存组件内存，不进入URL、DOM、持久存储或日志。刷新页面后需重新验证邮箱。
4. 注册响应中断不自动补发；保留原凭证供用户明确重试，同一凭证由后端消费记录恢复结果。连点提交由同步锁拦截。注册凭证已失效则要求重新验证，也可尝试登录。
5. 登录后重新取得轮换后的CSRF，再读取本人资料确认当前会话。首次昵称1—30个Unicode码点、去首尾空白、拒绝控制字符；后端确认保存前不能进入剧组工作台。
6. 资料版本冲突保留草稿，先明确读取当前版本，再另行保存，不自动覆盖。读取时若会话过期或换人，隐藏原资料并清除私有缓存。
7. 退出失败不声称已退出；隐藏私有工作区，显示结果未确认。跨标签页只广播无私人数据的`session-changed`消息，接收方重新向后端确认。窗口重新获得焦点也会检查会话。

## 3. 请求与界面约束

- Cookie由后端管理，前端只用同源请求；CSRF在内存保存。API请求15秒超时，但超时不能证明写入失败。网络、CSRF或服务故障均不透明重试写操作。
- 错误使用本地固定文案，不展示服务端任意原文；请求标识仅接受32位十六进制。前端验证改善交互，权限、字段规则与业务状态仍由后端校验。
- 红色区块使用黑字；沿用黑色顶栏、暖白背景、方角与细线。表单保留字段标签、加载状态及错误提示；移动端样式已编写，真实浏览器视觉检查尚未完成。
- 页面按需加载。账号阶段最大单个JS文件曾约295KB（未压缩），后续构建结果见剧组说明；这不是总包体积、首屏传输量或性能验收数据。
- 后续已接入剧组创建与查询。无假剧组、假计数或演示账号代替后端认证，Diane仍关闭。

## 4. 本地验证

在`frontend`执行`npm.cmd test`及`npm.cmd run build`；开发运行`npm.cmd run dev`，访问`http://127.0.0.1:5173/`。Vite代理`/api`到本机8000端口；完整注册依赖[邮件链路配置](mail-flow.md)，不能仅启动前端就完成注册。

本轮前端测试25项，覆盖表单主路径、强制昵称、版本冲突保留草稿、过期/换人清除缓存、退出不确定、注册断连显式恢复与防连点、CSRF轮换、不透明重试、响应校验及敏感字段不持久化。后端198项回归通过，包含新增202重发间隔字段校验。

验证工具仍有两类已知警告：前端jsdom不支持伪元素`getComputedStyle`，后端Starlette提示未来迁移httpx2；本轮未因此修改依赖。

本地开发页面HTTP返回200。Docker收到启动指令后仍未提供引擎，未启动容器或执行真实PostgreSQL迁移；不擅自重置或删除现有数据。浏览器检查工具因无法可靠确认URL停止操作，未完成视觉检查。保留上述事项为待验证，未使用真实邮箱或Qwen，也未更改根目录`.env`。
