## 核心代码怎么读

1. `backend/src/silencio_set/diane/model.py`：把 模型服务的地址、实际模型 ID 和密钥传给适配器。使用 Chat Completions，关闭思考模式，避免默认重试重复计费。
2. `tools.py`：把当前用户、剧组和请求标识固定在闭包中。模型只能提供任务 ID、分页或日期等业务参数；工具调用现有业务服务，复用页面权限和对象范围。
3. `runtime.py`：`model → tools → model`，直到返回回答或达到限制。按次记录模型与工具耗时，汇总用量，返回实际查过的记录依据。
4. `service.py`：先校验剧组身份，限制同时调用数量，完成后再检查成员访问权。
5. `frontend/src/diane/DianeLauncher.tsx`：模型功能启用后显示入口。一次提问对应一次独立查询，显示依据和耗时／token；不会把历史回答再次发给模型。

## 接口

前缀 `/api/v1/crews/{crew_id}/diane`。

| 接口 | 行为 |
|---|---|
| `GET` 前缀 | 当前成员查看是否启用、只读模式及调用时限，不返回模型地址或密钥 |
| `POST /queries` | 输入 `{"question":"下一次拍摄还有哪些准备事项？"}`；返回回答、状态、查询依据、模型／工具调用概况和用量 |

两者要求登录、完善昵称及有效剧组访问权。POST 还要求现有 Origin／CSRF 校验，每账号每分钟最多 6 次、每 IP 最多 12 次；输入最多 4000 字且沿用 16KiB 请求上限。客户端和 SDK 都不自动重试。工具目录不包含任意 SQL、文件路径、外部 URL、身份切换或写操作。

工具包括任务列表／详情、资源列表／详情／时段余量、计划列表／排期版本、下一场正式拍摄、剧组档期、指定场戏或分镜稿、实时变更清单。分页每次 10 条；权限不足不返回内容。创作稿目前需提供具体记录标识，来源链自动发现后续补齐；变更清单只覆盖已录入的关联记录，不能据此宣称筹备全面完成。

## 配置与边界

保留 `.env.example` 中的 `DIANE_ENABLED=false` 默认值。启用需要已有认证与数据库／Redis配置，并设置 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。地址填提供方的 HTTPS 兼容接口根地址，当前型号为 `deepseek-v4.1-flash`，北京地域兼容地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。原 `QWEN_*` 配置仍兼容，百炼的 `DASHSCOPE_API_KEY` 也可直接使用。密钥只保存在后端。

默认总模型工作时限 60 秒、模型调用最多 4 次、工具调用最多 8 次、单次输出最多 1500 tokens、总 token 调度预算 32000、上下文最多 48000 UTF-8 字节，同时最多 2 个请求。满载立即返回 429，不增加等待队列；这是单进程限制，未宣称高 QPS 能力。工具结果超过 16000 字节明确要求缩小查询，不截断后当成完整数据。

总耗时包括服务内身份检查；模型与工具耗时分别记录。提供方未返回完整 usage 时，实际 token 为 `null`，预算按输入 UTF-8 字节加输出上限及协议余量保守计入，估计与实际用量分开，不把未知用量填 0。预算为调度约束，不是精确账单。响应包含运行 UUID；模块 INFO 日志提供脱敏概况，需要日志部署启用对应日志级别。日志不包含问题、正文、完整工具结果或密钥；外部 LangSmith 跟踪显式关闭。

这是 FR-09、NFR-11 的首批实现，不代表完整 Agent 验收。尚未实现私有会话／运行记录持久化、断点恢复、异步队列、流式展示、任务提案、人工确认执行、自动创作或 RAG。没有业务状态写入，也没有新增数据库迁移。查询失败继续使用普通页面。

## 本地启用与数据发送说明

默认 `python scripts/browser_preview.py` 仍关闭模型；显式 `python scripts/browser_preview.py --diane` 才加载 `.env` 中的模型字段，保持现有试用数据库和私有文件目录，不导入 `.env` 内其他数据库／邮件配置。该开关不能与通知消费者或只建账号模式同时使用。环境变量优先于文件，新 LLM 名称优先于旧 QWEN 名称。密钥不写入启动参数或日志。

模型列表查询返回 200，已确认型号可见。实际剧组任务联调被自动审批拒绝，理由是尚未明确授权向外部模型发送这类私有业务数据；因此只使用虚构任务完成了真实模型验证。未绕过该拒绝。侧栏在提交前说明提问与查询到的资料将发送至阿里云百炼，状态接口只返回启用状态及型号，不返回密钥或接口地址。随后用户回复“ok继续”，明确授权这一页待处理任务数据的模型联调。授权范围之外的业务资料不自动用于进一步模型测试。
