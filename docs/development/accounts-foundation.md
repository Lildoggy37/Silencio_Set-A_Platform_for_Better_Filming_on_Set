# 账号模块第一步：数据、密码与昵称

本页保留第一步实施记录。后续验证码、会话与账号HTTP的当前进展见[认证流程说明](auth-flow.md)；下文“本轮”仅指第一步，不代表当前所有代码状态。

本轮只实现底层规则，不宣称注册、邮件或登录已可用；现有健康检查仍是唯一开放的业务外API。

## 2. 核心逻辑

注册时：邮箱先验证 → 服务端签发绑定邮箱的短期注册凭证 → 同一个PostgreSQL事务创建用户和凭证消费记录。消费记录的凭证摘要唯一，邮箱规范化值也唯一。**本轮仅提供表与校验结构，尚未实现验证码、凭证签发、跨存储衔接与注册事务**，不能把两个唯一约束当作完整注册幂等已完成。

昵称保存使用一次带条件的更新，而不是Python里“先查后改”：

```sql
UPDATE users
SET display_name = :display_name,
    profile_completed_at = COALESCE(profile_completed_at, :now),
    updated_at = :now,
    lock_version = lock_version + 1
WHERE id = :authenticated_user_id
  AND status = 'active'
  AND lock_version = :expected_lock_version
  AND lock_version < 2147483647
RETURNING ...;
```

这能表达“仅修改当前版本”，`COALESCE`用于保留第一次完成时间。SQLAlchemy使用绑定参数，不拼接用户输入。账号ID未来必须来自服务端会话，请求结构禁止传入他人ID及完成状态。服务函数不自行提交，调用者负责同一事务中的提交或回滚。

`profile_completed`由有效昵称及完成时间共同推导，不存独立布尔字段。未完成或停用账号有内部拒绝规则，但尚未接入HTTP授权；后续接口须转为既定的401/403/409响应并验证CSRF，不能把此内部函数当成已经部署的访问控制。

## 3. 本轮开发参数与边界

- 新密码暂定15—128个Unicode码点，允许空格、中文和口令短语，不要求复杂字符组合；保留原文，不做去空白、Unicode归一化或截断。历史较短密码在登录验证层仍可校验，不因新注册规则而直接拒绝。
- Argon2id初始参数：64MiB、3次迭代、并行度1，16字节随机盐、32字节输出，成熟库管理编码。参数升级只在密码验证成功后生成新散列，持久替换尚未接入登录事务。
- 这些是初始开发选择，不是压测结论。每次散列有CPU/内存成本；未来HTTP层须使用有界线程执行、并发限制及登录限流，不能直接阻塞异步事件循环。尚未实现泄露密码库筛查、未知账号的等成本验证及账号恢复。
- 参考[OWASP密码存储指南](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[认证指南](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)和[argon2-cffi接口文档](https://argon2-cffi.readthedocs.io/en/stable/api.html)选择实现，不据此宣称全部安全要求已满足。
- 邮箱仅做格式、IDNA及大小写规范化，不查DNS、不发送邮件；展示值保留去除首尾空白后的输入，不删除点号或`+`后缀。语法有效不代表邮箱存在或用户拥有它。国际化邮箱能否实际发送仍取决于后续邮件服务能力。
- 昵称去除Unicode首尾空白后1—30个码点，允许重名；内部控制字符、空字符及非法代理码点拒绝。数据库补充长度、成对非空、基本空白与控制字符约束，应用层Unicode校验更严格。码点计数不是字形簇计数。
- 输出采用显式字段白名单，密码散列、注册凭证及敏感内部字段不出现在用户资料视图。请求SecretStr会脱敏显示；仍禁止调用方记录请求原文或直接记录验证异常的原始输入。

密码与散列参数在原设计中尚未冻结，本节记录本次开发初值，后续根据实际安全与性能测试调整；账号接口上线前仍需补齐完整流程设计和测试。

## 4. 本轮验证

Windows/Python 3.12下，后端累计96项测试通过（较首批新增66项），`pip check`通过，迁移头为`0002_accounts`。覆盖邮箱与昵称边界、严格版本类型、敏感字段不回显、随机盐、正确/错误密码、旧散列升级、昵称更新SQL的版本条件与参数绑定、模拟服务结果和迁移离线SQL。保留原有Starlette/httpx弃用警告。

前端5项测试和TypeScript/Vite构建通过；红色拍摄区块及SS标识已改黑字，并同步UI规范，其他布局不变。已在本地浏览器核对红底黑字；本轮未启动API，页面如实显示无法连接，而非假在线。临时前端预览在验证后停止。

**未验证的部分**：真实PostgreSQL建表、数据库约束执行、两个真实事务并发保存、首次完成时间在真实库中的保留，以及Docker/Linux依赖安装。模拟与离线SQL测试不能证明这些已经通过。

本轮未改写真实`.env`，未发送邮件，未调用Qwen；未创建管理员或开发绕过登录入口，也未提交/推送代码。
